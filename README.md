# PlotFit

> Zeta 유저를 위한 플롯 맞춤형 대화 프로필 생성 서비스

## 만든 이유

Zeta에서 세계관이 짙은 플롯들을 쓰다 보면 기본 대화 프로필 하나로는 한계가 있습니다.
AI가 플롯 세계관을 제대로 못 읽고 엉뚱하게 반응하거나, 몰입이 깨지는 순간들이 생깁니다.

플롯마다 유저 대화 프로필을 맞춰주면 어떨까 싶어서 기획해보았습니다.

처음엔 Chrome 확장 프로그램으로 만들려 했는데,
Zeta는 앱 사용률이 압도적으로 높다는 걸 뒤늦게 깨달았습니다.
그래서 어디서든 쓸 수 있는 웹 서비스로 방향을 바꿨습니다.
(그래도 웹 제타에서 사용하는 것이 가장 편합니다😎)

## 서비스 플로우

외모·성격·배경·기타 입력 + 항목별 설정 유지 여부 선택 + 플롯 내용 붙여넣기
→ GPT가 플롯 세계관 분석
→ 세계관에 맞는 맞춤 구조화 프로필 생성
→ 복사해서 Zeta에 붙여넣기

프로필은 네 항목 중 하나 이상만 작성하면 됩니다. ‘설정 유지’는 기본 선택되며,
선택한 항목은 의미와 수치를 보존하고 표현만 다듬도록 AI에 요청합니다.
해제한 항목은 삭제하지 않고 세계관과 충돌하는 부분만 조정하도록 요청합니다.
프로필은 네 항목 합계 2,000자, 플롯은 10,000자까지 입력할 수 있습니다.

입력 JSON과 검증·호환성은 [항목별 프로필 입력](docs/structured-profile.md)을 참고하세요.
출력 Zod 검증은 데이터 구조를 확인하며, AI의 의미 보존을 보장하지는 않습니다.

## 한계와 개선 방향

- 웹 서비스라 별도 접속이 필요함 → Zeta 앱 내 기능(1피스로 생성)으로 통합되면 UX가 훨씬 자연스러울 것
- 지금은 프로필을 하나씩만 생성함 → 플롯별로 저장·관리하는 프로필 북으로 확장 가능
- 플롯 내용을 직접 붙여넣어야 함 → Zeta 플롯 URL 입력으로 자동 파싱 가능
